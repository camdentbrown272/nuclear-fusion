# 3D model — iteration 1 rev C

Generated by `sim/cad_dfm.py` (CadQuery; `pip install cadquery`). Every dimension comes from
`docs/design/iteration-1.md`; change a parameter at the top of the script and rerun to regenerate.

| File | Use |
|---|---|
| `dfm_cell.step` | Single DFM cell, editable CAD (Fusion 360, FreeCAD, SolidWorks, Onshape). True 12 µm membrane, full hex catch grid |
| `dfm_cell.stl` | Same cell as one mesh, for quick viewing or 3D printing (in mm) |
| `dfm_cell.glb`, `dfm_house.glb`, `gamma_station.glb` | Coloured meshes for any glTF viewer (Windows 3D Viewer, Blender, gltf-viewer.donmccurdy.com) |
| `dfm_house.step` | 8-position array in its Cu / ³He / borated-HDPE house (simplified cells) |
| `gamma_station.step` | NaI well calorimeter with the mini permeation cell in its Pb / borated-HDPE / veto shield (ADR-006) |
| `*.gltf.json` | Same meshes as self-contained glTF JSON, used by the web viewer |
| `viewer.html` | Interactive viewer (section cut, part descriptions) |

Run the viewer locally with `cd docs/design/cad && python3 -m http.server`, then open
<http://localhost:8000/viewer.html>. It loads three.js from a CDN.

The layers that are thinner than 0.1 mm are drawn at true thickness, except the Au exit finish
(50 nm, drawn 20 µm). The viewer can thicken the membrane, Au finish and ΔE detector ×40.
